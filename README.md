# Arbuz Surfer 🍉🏄‍♀️

Подарок Оле на день рождения: 3D-раннер в духе Subway Surfers. Оля катится по волне,
уворачивается от сообщений Паши Притчина, собирает арбузы и ловит поздравления — они бустят.

Играть: https://ndrwbv.github.io/arbuz-surfer/

- ← → / свайп — смена линии, ↑ / пробел — прыжок, ↓ — нырок, P — пауза
- Оля едет внутри трубы: ← на левой линии — заезд на стенку, ещё раз ← — 360 по трубе; иногда труба сужается и накрывает правую линию
- 🎁 подарок — буст ×2 и поздравление (сначала те, что оставили игроки; не повторяются, пока не собраны все)
- ☕ фильтр-кофе — полёт на кофейной тяге, 🐺 хаски — уносит Олю высоко и вперёд
- препятствия: сообщения Паши Притчина, акулы; «увольняюсь» Кирилла Швеца хлипкое — разбивается
- камео: Фёдор Овчинников передаёт привет, Жанна и Андрей пролетают на ковре-самолёте с кальяном
- локации: пирамиды → Москва-река → Нева → Томь; время суток: закат → ночь → рассвет → день
- 🍉 Бахча пожеланий (кнопка на старте и в конце): кубанское поле, Оля бегает (тап по полю / стрелки) или ездит на тракторе, разбивает арбузы с именами тремя тапами — внутри открытки

Пожелания и общий рейтинг — через Yandex Cloud Function и Object Storage, как настроить — [`serverless/README.md`](serverless/README.md).

Чистый three.js (CDN), без сборки: `index.html`, `style.css`, `js/game.js`.

После правок в `style.css` или `js/` перед коммитом запускать `./scripts/version.sh` — он проставляет версию в ссылки,
чтобы браузеры не брали старые файлы из кэша Pages.
